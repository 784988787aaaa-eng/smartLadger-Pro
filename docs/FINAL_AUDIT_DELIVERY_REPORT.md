اربط أدلة التحقق برمز commit واحد، وسجّل:

1. رأس الفرع ورمز commit الذي جرى اختباره.

3. نتيجة `dotnet build SmartLedger.sln -c Release --no-restore` وعدد الأخطاء والتحذيرات.
4. نتيجة `dotnet test tests/SmartLedger.Tests/SmartLedger.Tests.csproj -c Release --no-build --verbosity normal` وعدد الاختبارات الناجحة والفاشلة والمتجاوزة.

7. اختبارات للقيم المالية غير الصالحة، والخصم الذي يتجاوز الإجمالي، وعكس الفاتورة وآثاره على القيود والمخزون.
