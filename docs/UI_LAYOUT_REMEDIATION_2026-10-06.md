# Smart Ledger — UI Layout Remediation
## 2026-10-06

### الهدف
إغلاق عيب تخطيط نوافذ الإدخال الذي كان يجعل محتوى الصفحة يتزحزح أو ينكمش عند ظهور نافذة الإدخال، مع توحيد الاختصارات وسلوك الإدخال على مستوى التطبيق.

### ما تم تغييره
1. **DialogOverlay مركزي**
   - تمت إضافة Style باسم DialogOverlay.
   - يستخدم Grid.RowSpan/Grid.ColumnSpan بقيمة 999 لتغطية كامل مساحة الصفحة.
   - يعمل كطبقة مستقلة فوق المحتوى ولا يدخل في قياس تخطيط الصفوف.
   - تم ربط نوافذ الحسابات والمخزون والنفقات به.
   - النتيجة: ظهور الحوار لا يغير مواقع الجداول أو البطاقات أو العناوين خلفه.

2. **Keyboard-first**
   - Ctrl+K يضع التركيز مباشرة في البحث العام.
   - Ctrl+N يفتح إضافة حساب/صنف/نفقة بحسب الصفحة الحالية، وفي الصفحات الأخرى يضع التركيز على أول حقل إدخال.
   - Ctrl+S ينفذ الحفظ المناسب للسياق.
   - F5 يعيد تحميل بيانات الصفحة الحالية.
   - Esc يغلق الحوار النشط قبل أي سلوك آخر، ويخرج من Full Screen عند عدم وجود حوار.
   - F11 للتبديل بين Full Screen والوضع العادي.

3. **ثبات الأرقام**
   - NumericField وNumericCell مستمران باستخدام اتجاه LeftToRight ومحاذاة رقمية وLanguage=en-US.
   - هذا يثبت عرض الأرقام الغربية 0-9 داخل الحقول والقوائم والجداول.

4. **توحيد النافذة**
   - البحث العام أصبح له اسم GlobalSearchBox لتمكين التركيز البرمجي المباشر.
   - تمت إضافة شريط اختصارات هادئ أسفل عنوان الصفحة في الـTopBar.
